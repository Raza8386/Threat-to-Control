# Threat to Control

Grounded cybersecurity Q&A that answers only from MITRE ATT&CK, OWASP Top 10 and CISA KEV, cites every claim, blocks prompt injection, and publishes its own eval scores — extended with NCA ECC / SAMA CSF control mapping and an audit-finding mode.

Status: Phase 1 (data and store) in progress. See `CLAUDE.md` for the architecture and phase gates.
